# Changelog

All notable public-contract changes to Genesis Shadow Glass UI are recorded here.

## 0.1.0-alpha.0 — Unreleased

### Added

- Canonical Shadow Glass tokens, typography, density, and reduced-effects profiles.
- Framework-neutral registration with forty-one initial `sg-*` custom elements.
- Buttons, icon buttons, native-backed inputs, selects, toggles, sliders, checkboxes, radio groups, textareas, number steppers, chips, interaction prompts, action lists, hold confirmations, popovers, context menus, radial menus, breadcrumbs, pagination, progress, meters, avatars, list rows, empty states, skeletons, data tables, tabs, segmented controls, modal and drawer shells, tooltips, toasts, surfaces, badges, icons, status capsules, item slots, alerts, keybinds, and dividers.
- Typed activation, value-input, value-change, close, item-activation, and dismissal event contracts.
- Local Exo 2 and Inter variable fonts and a generated Lucide icon sprite.
- No-build minimal consumer, component catalogue, and package-local HELIX harness.
- Reproducible build, distribution manifest, offline-reference checks, and size budgets.
- Searchable catalogue workbench with live component controls, generated markup, contract documentation, clipboard fallback, and an `sg-*` event channel.
- Refined action, status, inventory, alert, badge, and keybinding treatments with clearer non-color state cues and readable compact metadata.
- Multi-key chord rendering for `sg-keybind`, meaningful-only stat progress semantics, semantic alert icons, and distinct locked item-slot anatomy.
- Wedge-based radial menus with four, six, and eight-segment geometry, centered labels and icons, a dedicated hub, and full-slice interaction states.
- Registered-consumer synchronization with `sync` and read-only drift detection with `sync:check`.
- Architecture, contributor, handoff, and ready-to-post Discord documentation for the source-of-truth and controlled-propagation model.
